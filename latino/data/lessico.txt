# aMICOLatino – lessico di base del primo anno.
# Tutte le voci sono "da verificare" con la professoressa finché non vengono segnate come verificate.
#
# Formato di ogni riga:
#   paradigma | categoria | significati (separati da ;) | caso retto | esempio | etichette
# Categorie: n = nome, agg = aggettivo, v = verbo, pron = pronome, avv = avverbio,
#            prep = preposizione, cong = congiunzione, inter = interiezione, num = numerale.
# Etichette principali: conn=tipo (connettivo), forme=a/ab (varianti), gpl=um / abl=i (3ª declinazione),
#   pl (solo plurale), comp= / sup= / avv= (gradi irregolari), nocomp, pronominale, pron=… (tabella del pronome),
#   extra=forma:caso.numero (forme particolari), id=… (per distinguere due voci uguali).
